# Faro

**A lightweight package manager for Linux From Scratch.**

Faro is an experimental package manager designed with LFS as a main target in mind. 
Although it can theoretically be installed on any Linux distribution, there is little reason to do so, as it would simply act as a secondary package manager.

## Features

- Building package from source using faro_recipe.json
- Installing built package
- faro keeps track of installed packages, libraries and dependencies
- Updating/Downgrading installed packages with its dependencies ( only development branch )
- Complete removal of package with all files generated by it ( only development branch )

## Requirements

- C++20 compiler (GCC or Clang)
- libarchive
- nlohmann/json

## Building

Clone the repository:

```bash
git clone git@github.com:unlstd/faro.git
cd faro
```

Compile Faro:

```bash
make
```

Install Faro:

```bash
sudo make install
```

## Package recipes

Source packages use a `faro_recipe.json` file to describe their build process.

Example:

```json
{
  "name": "example",
  "version": "1.0.0",
  "description": "An example package",
  "dependencies": [],
  "build": [
    ["make", "-j4"]
  ],
  "install": [
    ["make", "install"]
  ]
}
```

Faro uses these instructions to build and stage packages before installing to the system.

## Usage

Build a package:

```bash
faro build package.tar.xz
```

Install a prebuilt package:

```bash
sudo faro install package.tar.xz
```
